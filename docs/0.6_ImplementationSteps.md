## 🧩 Phase 1: Core Skeleton & Bootstrap Stub

Mục tiêu của giai đoạn này là **tạo khung xương tối thiểu** để ứng dụng FastAPI có thể khởi động, dù chưa có domain, infra hay service.

---

#### **1️⃣ Core**

* **`backend/app/core/config.py`**

  * Định nghĩa lớp `Settings` (Pydantic) và hàm `get_settings()`.
  * Dùng để quản lý cấu hình `.env` (ví dụ `APP_ENV`, `OPENAI_API_KEY`, `VECTORSTORE_PATH`, ...).

* **`backend/app/core/logging.py`**

  * Cấu hình logging chuẩn cho toàn ứng dụng (format, level, stream handler,...).

---

#### **2️⃣ Bootstrap Stub**

* **`backend/app/bootstrap.py`**
  Stub tạm thời để main có thể import mà không lỗi:

  ```python
  def bootstrap_dependencies(app, settings, *, force_reindex: bool = False) -> None:
      pass
  ```

> 🔹 *Phase 7 sẽ “điền thịt” cho hàm này để khởi tạo vectorstore, embedding, repository, services,…*

---

#### **3️⃣ Router Rỗng (API Skeleton)**

* **`backend/app/api/routes/__init__.py`**

  ```python
  from fastapi import APIRouter

  api_router = APIRouter()
  ```

* **(Tùy chọn)** Thêm route kiểm tra hệ thống:

  ```python
  # backend/app/api/routes/health.py
  from fastapi import APIRouter

  router = APIRouter()

  @router.get("/health")
  def health():
      return {"status": "ok"}
  ```

  Và include trong `__init__.py`:

  ```python
  from . import health
  api_router.include_router(health.router)
  ```

---

#### **4️⃣ Main App**

* **`backend/app/main.py`**

  ```python
  from fastapi import FastAPI
  from fastapi.middleware.cors import CORSMiddleware
  from app.core.config import get_settings
  from app.bootstrap import bootstrap_dependencies
  from app.api.routes import api_router

  settings = get_settings()
  app = FastAPI(title=settings.app_name)

  app.add_middleware(
      CORSMiddleware,
      allow_origins=["*"],
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )

  bootstrap_dependencies(app, settings)
  app.include_router(api_router)
  ```

---

#### ✅ **Kết quả sau Phase 1**

* FastAPI khởi động thành công (`uvicorn app.main:app --reload`).
* Route `/health` trả về `{ "status": "ok" }` nếu có.
* Sẵn sàng mở rộng sang **Phase 2 (Domain)** mà không cần chỉnh lại phần core.

## **Phase 4: Application Services (Use Cases)**

* **`document_service.py`** – Lưu metadata, reset/reindex, đếm vectors.
* **`conversation_service.py`** – Tạo/lấy hội thoại, giới hạn lịch sử.
* **`chat_service.py`** – Orchestrate retrieval → LLM → trả lời.

> 🔹 *Các service sử dụng port, không phụ thuộc framework web.*

---

## **Phase 5: Ingestion (Orchestration)**

* **`splitters.py`** – Tách chunk văn bản.
* **`loaders.py`** – Đọc file (txt/pdf/csv…) → chuẩn hóa.
* **`pipeline.py`** – Pipeline: load → split → embed → upsert vectorstore.

> 🔹 *Ingestion đóng vai trò application layer cho dữ liệu đầu vào.*

## **Vertical Slice Tối Thiểu (để chạy được)**

| Layer     | Files cần có                                                                    |
| --------- | ------------------------------------------------------------------------------- |
| Core      | `config.py`, `logging.py`, `main.py`                                            |
| Domain    | `models/document.py`, `interfaces/vector_store.py`                              |
| Infra     | `vectorstores/chroma.py`, 1 embedding + 1 LLM                                   |
| Ingestion | `splitters.py`, `pipeline.py` (support `.txt`)                                  |
| Services  | `document_service.py`, `chat_service.py`                                        |
| API       | `routes/health.py`, `routes/documents.py`, `routes/chat.py` + schemas tương ứng |
| Bootstrap | `bootstrap.py`                                                                  |

---

## **Kiến trúc & Nguyên tắc chính**

* **Port nằm ở domain**, **infra implement**.
* **Ingestion là orchestration layer**, chỉ dùng port, không phụ thuộc infra.
* **API** gọi **services**, không chứa logic.
* **Config** tập trung tại `core/config.py` – một nguồn sự thật cho settings.
